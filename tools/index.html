How the tools are checked

Each calculation is written once and used by both the page and an automated test. The tests compare it with worked textbook examples and with an independent reference: an astronomical ephemeris for the Sun, a geodesic library for distances, and brute-force simulation for wind, current and radar plots. A tool is published only when every test passes.
